# Ανίχνευση και εκτίμηση εγγύτητας συσκευών Bluetooth Low Energy

Εφαρμογή Python που:

- ανιχνεύει κοντινές συσκευές BLE (όνομα, αναγνωριστικό, τελευταίο RSSI, χρόνος τελευταίας ανίχνευσης),
- παρακολουθεί μία επιλεγμένη συσκευή με γράφημα RSSI στον χρόνο (αρχικό και εξομαλυμένο),
- εξομαλύνει τις μετρήσεις με εκθετική εξομάλυνση (EMA) ή κινητό μέσο όρο,
- κατατάσσει τη συσκευή ως **κοντά**, **μεσαία απόσταση** ή **μακριά**, με όρια από πειραματικές μετρήσεις,
- στη λειτουργία αναζήτησης δείχνει **πιθανότατα πλησιάζετε**, **πιθανότατα απομακρύνεστε** ή **χωρίς σαφή μεταβολή**,
- εξάγει τις μετρήσεις σε CSV και, όταν διακοπεί η λήψη, εμφανίζει **δεν ανιχνεύεται** (όχι «μακριά»).

Υλοποιεί και τις προαιρετικές επεκτάσεις: εκτίμηση απόστασης σε μέτρα, σύγκριση με ταξινομητή
μηχανικής μάθησης, ηχητική ένδειξη αναζήτησης και επαναπροβολή αποθηκευμένης συνεδρίας.

## Απαιτήσεις

- Windows 10/11 (δοκιμασμένο), Linux ή macOS
- Python 3.10 ή νεότερη έκδοση
- Υπολογιστής με ενεργό προσαρμογέα Bluetooth LE
- Συσκευή δοκιμών που εκπέμπει BLE advertisements

| 2. Εφαρμογή (προσομοίωση) | Η ίδια εφαρμογή με προσομοιωμένες συσκευές, για επίδειξη χωρίς Bluetooth |

## Εκτέλεση από τη γραμμή εντολών

```bash
.venv\Scripts\python -m ble_proximity
```

```bash
.venv\Scripts\python -m ble_proximity --simulate --autostart
```

Χρήση της εφαρμογής:

- Πατήστε **Έναρξη σάρωσης** και κάντε διπλό κλικ σε μια συσκευή για να την παρακολουθήσετε.
- Στο πλαίσιο «Επεξεργασία μετρήσεων» αλλάζετε μέθοδο εξομάλυνσης (EMA α ή κινητό μέσο N) και το όριο «δεν ανιχνεύεται». Το ιστορικό επανυπολογίζεται αμέσως.
- **Εξαγωγή CSV…** αποθηκεύει τη συνεδρία στο `data/sessions/`. **Επαναπροβολή…** την ξαναπαίζει (μενού *Αρχείο* για ταχύτητα 1×–10×).
- Η επιλογή **Ηχητική ένδειξη αναζήτησης** ενεργοποιεί «μπιπ» που πυκνώνουν όσο πλησιάζετε.

## Πειραματική διαδικασία

**Συσκευή δοκιμών.** Τα κινητά αλλάζουν συχνά διεύθυνση Bluetooth (MAC randomization) και πολλές συσκευές
δεν εκπέμπουν συνεχώς. Προτείνεται ένα BLE beacon ή εφαρμογή advertiser σε κινητό (π.χ. *nRF Connect →
Advertiser*) με **σταθερό όνομα**. Στο `--target` δίνετε μέρος αυτού του ονόματος.

1. Βρείτε τη συσκευή:

   ```bash
   .venv\Scripts\python -m ble_proximity.record --list
   ```

2. Για κάθε απόσταση (1, 2, 3, 5 m), κάθε συνθήκη και κάθε επανάληψη (1, 2, 3) καταγράψτε 60 s:

   ```bash
   .venv\Scripts\python -m ble_proximity.record --target "MyBeacon" --distance 1 --condition los --rep 1
   ```

   | Κωδικός συνθήκης | Περιγραφή |
   |---|---|
   | `los` | Οπτική επαφή |
   | `obstacle` | Εμπόδιο ανάμεσα (σημειώστε το είδος με `--note`) |
   | `orient90`, `orient180` | Συσκευή στραμμένη 90° / 180° |

   Τα αρχεία αποθηκεύονται στο `data/experiments/` (π.χ. `los_d1m_rep1.csv`). Σύνολο: 4 αποστάσεις × 4 συνθήκες × 3 επαναλήψεις = 48 καταγραφές.

3. Αναλύστε:

   ```bash
   .venv\Scripts\python -m ble_proximity.analyze
   ```

   - Τα όρια προκύπτουν **μόνο από τις επαναλήψεις 1 και 2**. Η αξιολόγηση γίνεται **στην επανάληψη 3**, όπως ζητά η εκφώνηση. Αλλάζει με `--cal-reps` / `--test-reps`.
   - Τα όρια γράφονται στο `config/thresholds.json` και η εφαρμογή τα φορτώνει αυτόματα (ή από το μενού *Ρυθμίσεις → Επαναφόρτωση ορίων*).
   - Τα γραφήματα και ο πίνακας αποτελεσμάτων γράφονται στο `analysis/` (`results.md`, `*.png`) για την αναφορά.
   - Χρήσιμες επιλογές: `--smoothing ma --param 10`, `--fit-conditions los`, `--near-max 1.5 --medium-max 3.5`.

Για έλεγχο της ανάλυσης πριν από τα πειράματα υπάρχουν **συνθετικά** δεδομένα. Αυτά δεν είναι μετρήσεις και δεν μπαίνουν στην αναφορά:

```bash
.venv\Scripts\python -m tests.make_synthetic_data --out data/synthetic
```

```bash
.venv\Scripts\python -m ble_proximity.analyze --data data/synthetic --out analysis/synthetic --no-write-thresholds
```

## Αρχιτεκτονική

```
ble_proximity/
├── sources.py     Πηγές μετρήσεων σε ξεχωριστό νήμα: BLE (bleak), προσομοίωση, επαναπροβολή
├── processing.py  Εξομάλυνση (EMA/MA), κατάταξη με υστέρηση, τάση (κλίση), DeviceTracker
├── gui.py         Γραφική διεπαφή tkinter + γράφημα matplotlib
├── storage.py     Εξαγωγή/ανάγνωση CSV
├── record.py      Καταγραφή πειραμάτων από τη γραμμή εντολών
├── analyze.py     Ρύθμιση ορίων, αξιολόγηση, γραφήματα, μοντέλο απόστασης, ML
├── sound.py       Ηχητική ένδειξη αναζήτησης
└── config.py      Ρυθμίσεις, ετικέτες, όρια (config/thresholds.json)
```

Ροή δεδομένων: `BleakScanner → ουρά → DeviceTracker (εξομάλυνση → κατάταξη → τάση) → GUI / CSV`.

## Μέθοδοι επεξεργασίας

- **Εξομάλυνση:** EMA `y[k] = α·x[k] + (1−α)·y[k−1]` (προεπ. α = 0.2) ή κινητός μέσος N δειγμάτων. Μετά από διακοπή λήψης το φίλτρο μηδενίζεται.
- **Εγγύτητα:** σύγκριση του εξομαλυμένου RSSI με δύο όρια, με υστέρηση ±1 dB ώστε να μην «τρεμοπαίζει» η ένδειξη κοντά στα όρια.
- **Τάση:** κλίση ευθείας ελαχίστων τετραγώνων στα τελευταία 6 s του εξομαλυμένου RSSI. Κλίση ≥ +0.4 dB/s σημαίνει «πλησιάζετε», ≤ −0.4 dB/s «απομακρύνεστε».
- **Δεν ανιχνεύεται:** χωρίς λήψη για 5 s (ρυθμίζεται), η ένδειξη γίνεται «δεν ανιχνεύεται» και όχι «μακριά».
- **Απόσταση:** μοντέλο log-distance `RSSI = A − 10·n·log10(d)`, με A και n από τις μετρήσεις οπτικής επαφής.
